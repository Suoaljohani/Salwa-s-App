# مساعد سلوى للإحصاء الطبي

تطبيق خاص لرئيسة قسم الإحصاء الطبي بمستشفى الحديثة العام للإحصاء العام على **أي** بيانات تُرفع (زيارات، موظفون، أسرّة، عمليات…): محادثة عربية تعطي الرقم الصحيح بوحدته وفترته ومصدره، ولوحة مؤشرات تتكيف مع كل قاعدة بيانات، واستيراد بيانات، وتعبئة نماذج Excel الواردة، واستخراج تقارير Excel جديدة.

### قواعد البيانات العامة
- كل ملف Excel/CSV يصبح «قاعدة بيانات» بأعمدة لها نوع (نص، رقم، تاريخ، تاريخ ووقت، نعم/لا) ودور (فئة، قيمة رقمية، تاريخ، معرّف مشفّر، أو لا يُحفظ).
- **لقطة** (مثل الموظفين): أحدث ملف معتمد يحل محل السابق. **تراكمي** (مثل الزيارات): كل ملف يضيف فترة بتغطية واضحة، والنسخة المصححة تحل محل فترتها، ويمنع المفتاح التكرار.
- المحرك الموحد `dataset_query`: عدد، عدد مميز، مجموع، متوسط، أدنى، أعلى؛ مرشحات على أي عمود؛ توزيع على عمودين؛ فترات بتوقيت الرياض؛ فئات عمرية/رقمية.
- تقرير الزيارات من نظام المستشفى يُتعرّف عليه تلقائيًا (قالب جاهز).
تطبيق iPhone أصلي (ملف IPA عبر Capacitor) يعمل بالإنترنت، وتعمل الواجهة نفسها كذلك في المتصفح.

## البنية

| الطبقة | التقنية |
|---|---|
| الواجهة | React 19 + TypeScript + Vite، Motion للحركة، ECharts للرسوم، Base UI للنوافذ والمفاتيح، أيقونات Lucide |
| البيانات | Supabase (مشروع «Stat app»): PostgreSQL مع RLS، تخزين خاص `private-files`، حساب واحد مسموح |
| محرك الإحصاء | دالة `dataset_query` في قاعدة البيانات لأي قاعدة بيانات — نفسها تخدم المحادثة والمؤشرات والتعبئة والاستخراج |
| الفهم الذكي | دالة Edge `assistant` ← Groq (`openai/gpt-oss-120b`) باستدعاء أدوات؛ النموذج لا يكتب الأرقام |
| الاحتياط | محلل عربي بالقواعد يعمل عند بلوغ الحد المجاني أو تعذّر الخدمة، وفي الوضع التجريبي |

المجلدات: `src/` الواجهة، `supabase/migrations/` المخطط والمحرك، `supabase/functions/assistant/` الخدمة الذكية، `tests/` الاختبارات، `DESIGN.md` و`MOTION.md` قرارات التصميم والحركة، `.claude/skills/` مهارات الحزمة.

## التشغيل

```bash
npm ci
# ضع ملفي الخط JannaLT-Regular.ttf و JannaLT-Bold.ttf في public/fonts/ (خط مرخّص، غير موجود في المستودع العام)
npm run dev        # http://localhost:5173
npm test           # اختبارات المحرك والمحلل وExcel
npm run build      # ينتج dist/
```

الإعداد العام في `.env.example` (المفتاح المنشور مخصص للمتصفح؛ الحماية في RLS). لا توجد أسرار في الواجهة.

## ملف IPA لتطبيق iPhone

- يُبنى تلقائيًا على جهاز Mac من GitHub Actions (`.github/workflows/ios.yml`) عند كل دفع إلى `main`، أو يدويًا من تبويب **Actions ← iOS IPA ← Run workflow**.
- بعد انتهاء التشغيل: افتحي صفحة التشغيل ← قسم **Artifacts** ← نزّلي `Salwa-unsigned-ipa` (ملف ZIP بداخله `Salwa-unsigned.ipa`).
- **التثبيت دون حساب مطور مدفوع:** ملف IPA غير موقّع لا تقبله أجهزة iPhone مباشرة. يُوقّع ويُثبّت بأداة مثل **Sideloadly** أو **AltStore** من جهاز كمبيوتر بحساب Apple ID عادي؛ التوقيع المجاني صالح 7 أيام ثم يُجدد من الأداة نفسها.
- **توقيع دائم:** مع حساب Apple Developer أضيفي أسرار GitHub التالية فيُنتج التشغيل أيضًا `Salwa-signed-ipa` جاهزًا للتثبيت (Ad Hoc) أو للرفع إلى TestFlight:
  `IOS_CERT_P12_BASE64`، `IOS_CERT_PASSWORD`، `IOS_PROFILE_BASE64` (لمعرّف `com.salwa.medstats`)، `IOS_TEAM_ID`، واختياريًا `IOS_EXPORT_METHOD`.
- البناء محليًا على Mac: `npm ci && npm run build && npx cap sync ios && npx cap open ios` ثم Run من Xcode.
- خط Janna LT غير موجود في المستودع العام؛ إن لم يكن في `public/fonts/` وقت البناء يستخدم التطبيق خط iOS العربي. لتضمينه: اجعلي المستودع خاصًا ثم أضيفي ملفي الخط.

## خطوات متبقية على حساب Supabase (مرة واحدة)

1. **مفتاح Groq:** Supabase ← Edge Functions ← Secrets ← أضيفي `GROQ_API_KEY`. (حتى إضافته تعمل المحادثة بالمحلل المحلي وتذكر ذلك تحت الإجابة.)
2. **حساب سلوى:** Authentication ← Users ← Add user (بريد وكلمة مرور). أول دخول لهذا الحساب يثبّته مالكًا وحيدًا؛ يُرفض التثبيت إذا وُجد أكثر من مستخدم.
3. **إغلاق التسجيل العام:** Authentication ← Sign In / Providers ← عطّلي «Allow new users to sign up».
4. **أول بيانات:** من صفحة «البيانات» ارفعي تقرير الزيارات، راجعي الربط والتغطية، ثم «اعتماد».

المهاجرات تُطبّق تلقائيًا عبر ربط GitHub مع Supabase عند الدفع إلى `main`.

## قواعد الدقة المطبقة

- الزيارات ≠ المرضى المختلفون (المريض يُعد مرة واحدة عبر معرّف مستعار HMAC لرقم الملف).
- العمر وقت الزيارة كما ورد في المصدر؛ «18 فأكثر» تشمل 18.
- حدود الأيام والأشهر بتوقيت الرياض: `[البداية 00:00، النهاية غير شاملة)`.
- الفترة غير المغطاة = «غير متاح» (null)، والفترة المغطاة بلا سجلات = 0. التغطية الجزئية تُذكر بعدد الأيام والفجوات.
- السجل بلا قيمة للحقل المرشَّح يُستبعد ويُذكر عدده.
- الملف نفسه لا يُستورد مرتين (بصمة SHA-256)، والنسخة المصححة لشهر تحل محل السابقة داخل فترتها، والتراجع يعيدها.
- لا تُحفظ الأسماء أو الهوية الوطنية أو الجوال؛ لا تُرسل أي صفوف مرضى إلى النموذج — فقط السؤال وأسماء الفئات.
- CTAS والتشخيص غير موجودين في تقرير الزيارات الحالي، فيجيب التطبيق بأنهما غير متاحين بدل التخمين.

## الفحوص التي نُفذت فعليًا (18 نوفمبر 2026)

- `npm test`: 24 اختبارًا ناجحًا (حالات المحرك الحدية، المحلل العربي، تقرير Excel، تعبئة نموذج مع التحقق من بقاء الصيغ والتنسيق والدمج والطباعة، تحليل الاستيراد).
- **مطابقة مستقلة على الملف الحقيقي:** حساب Python منفصل (openpyxl) مقابل محرك TypeScript على `All_Patient_Visit_Report_New_9.xlsx` — 12 سؤالًا متطابقة (مثل يوليو 2026: 1,139 زيارة؛ طوارئ 18+ = 558 مع استبعاد 2 بلا عمر؛ 765 مريضًا مختلفًا في الطوارئ؛ يونيو = غير متاح).
- **محرك SQL العام:** `supabase/tests/engine_check.sql` (زيارات + موظفين، تصحيح، تراجع، استبعاد الأعمدة الشخصية، رفض الأعمدة المجهولة) يُشغَّل من محرر SQL في Supabase وينتهي بتراجع تلقائي. نُسخة المحرك الخاصة بالزيارات فقط اجتازت الفحص الحي سابقًا؛ فحص المحرك العام الحي ينتظر الموافقة.
- **Groq:** النموذج `openai/gpt-oss-120b` متاح بالحساب؛ استدعاء الأدوات مُختبر مباشرة (~0.3–0.9 ث، ~1,400 رمز للسؤال). الحدود المقروءة من الحساب: 1,000 طلب يوميًا و8,000 رمز في الدقيقة (≈ 5 أسئلة جديدة في الدقيقة؛ الأسئلة المكررة من الذاكرة المؤقتة).
- **المتصفح (Chromium):** لقطات 390px و320px و1280px، فاتح وداكن، خط 140٪، شفافية مخفضة، حركة مخفضة؛ لا تجاوز أفقي ولا أخطاء في وحدة التحكم. تسلسل دخول المؤشرات مُسجّل إطارًا بإطار (~650 مللي ثانية).
- **لم يُختبر بعد:** جهاز iPhone فعلي، الصوت بالسمع، تسجيل الدخول الحقيقي (لا يوجد حساب بعد)، استدعاء Groq من دالة Edge (ينتظر المفتاح)، نماذج Excel رسمية حقيقية من الجهات.

## الحجم والخطط المجانية

قاعدة البيانات الآن 11 م.ب من 500 م.ب. التقدير: ~600 بايت لكل زيارة (نسخة مجهزة + نشطة + فهارس). عند نحو 1,200 زيارة شهريًا (حجم الملف المرفق) يكون النمو ~9 م.ب سنويًا، وملفات الأصل ~3.5 م.ب سنويًا من 1 ج.ب. هذا تقدير يُراجع بعد استيراد سنوات فعلية؛ تعرض صفحة الإعدادات الحجم الحالي.

## حدود معروفة

- تعبئة Excel تستخدم ExcelJS: تتوقف عمدًا إذا احتوى النموذج رسومًا بيانية أو جداول محورية أو ماكرو أو روابط خارجية، لأنها لا تُحفظ بدقة. الصيغ تُترك ويُعيد Excel حسابها عند الفتح (`fullCalcOnLoad`).
- فهم الخانات في النماذج مقترح من العناوين ويحتاج تأكيد سلوى.
- المصدر المدعوم حاليًا: تقرير الزيارات التفصيلي (سجل لكل زيارة) بصيغة XLSX/CSV.
- خط Janna LT مرخّص وغير مضمّن في المستودع العام.
